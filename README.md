# Artemlist

Личные заметки для iPhone (iOS 17+). SwiftUI + SwiftData, без сервера и ИИ.

- Текст, ссылки и скриншоты из Фото.
- Поиск по названию, тексту и ссылке.
- Локальное хранение, работа без интернета.
- Напоминания: однократно, ежедневно, еженедельно; перенос и завершение внутри заметки.

## Запуск на iPhone
На Mac установите Xcode и XcodeGen (`brew install xcodegen`).
В каталоге проекта выполните `xcodegen generate`, откройте Artemlist.xcodeproj.
В Signing & Capabilities выберите свой Apple Team и уникальный Bundle Identifier.
Подключите iPhone, выберите его в Xcode и нажмите Run.
GitHub Actions проверяет сборку для симулятора; это не установочный файл для iPhone.

## Ограничения первой версии
Нет синхронизации и расширения «Поделиться». Фото добавляются через системный выбор фотографий.
Напоминания требуют разрешения уведомлений. Действия «Готово» и «Отложить» доступны в редакторе.
Удаление приложения удаляет его локальные данные. Экспорт пока не реализован.
